# Milk Payment Calculator — Python Assignment 1

A beginner-friendly Python 3 project based on the assignment scenario for Ksheera Village Milk Producers' Co-operative.

## Files
- `milk_payment.py` — validated interactive calculator, including seasonal rates and ten-day bonus helper.
- `milkrate.py` — reusable rate and payout functions.
- `explore_types.py` — type(), division, modulo, and floating-point demonstrations.
- `execution_outputs.txt` — actual output captured by running the programs.
- `screenshots/` — terminal-style images generated from the captured execution output.

## Run
```bash
python milk_payment.py
python milkrate.py
python explore_types.py
```

## Tariff assumptions
- Normal base rate: ₹30.00/litre at 3.5% fat and 8.5% SNF.
- Each 0.1% fat step: ₹0.40/litre.
- Each 0.1% SNF step: ₹0.30/litre.
- April–June seasonal base rate: ₹32.00/litre and fat adjustment ₹0.45 per 0.1% step.
- Bonus helper: if ten-day supply exceeds 500 litres, bonus is 50 paise per litre of the total. Confirm this interpretation with the instructor/co-operative.

## Important
This project has been run locally in the prepared environment. The screenshots document those actual program outputs; they are not screenshots from the student's own laptop. Run the programs on your own computer and capture your own IDE/terminal screenshots if required by the instructor.
